# v2.2.1 审查记录

审查对象为本仓库 Skill、Python 核心、CLI/MCP、示范模型、文档及分发流程。网络交叉核对使用 Vensim 官方函数与格式文档、PySD 文档/源码、MCP 官方安全资料及系统动力学原始研究规范；Exa 与内置搜索互相核对，库 API 另查 Context7。

## 已修复的问题

| 问题 | 影响 | 修复与证据 |
| --- | --- | --- |
| ZIDZ 误用三个参数，小分母仅检测精确零 | 合法公式失败，接近零时返回错误的大数 | 两参数语法与原生 `1e-6` 保护；边界回归 |
| 固定延迟每时刻重读时长/初值、即时插值，未作为状态处理 | 时变时长错误、短延迟即时输出、反馈报代数循环 | 独立状态、初始化冻结、离散取整、同步更新；实际 PySD 对照 |
| PULSE 不处理零宽度及半步比较 | 零宽脉冲丢失、非网格边界偏差 | 按官方说明实现并明确跨后端差异 |
| 名称按精确大小写/空格比对 | 合法原生引用失败，等价重复漏检 | 原生等价匹配、重复拒绝、Defined/库存/反馈映射检查 |
| 隐式状态等价重名、新建器接受需加引号的名称 | 状态与业务变量错配，生成不合规的无引号名称 | 隐式状态按原生名称等价判重；新建器限定支持的名称并说明已有模型边界 |
| Lookup 显示范围可能参与插值，独立表/科学计数法不完整 | 数据点或插值值错误 | 只读取真实点，支持原生形式，错误点拒绝；历史示范括号修正 |
| 嵌套函数中的内部别名可再匹配业务名 | 特定变量名导致计算错配 | 占位符保留至最外层，有专门冲突回归 |
| 方程结果未统一拒绝非有限常量 | 成功 CSV 可能含 Inf | 有限数检查、时间精度和隐式/延迟状态资源检查 |
| CSV 导入丢失诊断与实验身份 | 失败替代值可再次作为正式图，大量抽样身份丢失 | 相邻清单恢复、哈希核对、诊断拒绝、单位核对 |
| MCP 输出解析先跟随断裂符号链接 | 可能向本应保留的链接目标写入结果 | 解析前拒绝已存在/断裂输出链接；真实协议回归 |
| 规范仅有默认 lint，没有统一格式和现代类型规则 | 风格与工程约束易漂移 | `pyproject.toml`、Ruff lint/format、异常链与闭包约束、CI 格式检查 |
| 英文仓库说明缺失 | 安装、调用和限制不便英文读者核对 | 完整 `README.en.md`，双向导航与本地链接检查 |
| 重新解析版本合规，但本机旧依赖不符合约束 | 只查解析报告可漏掉实际旧包 | `doctor` 检查已安装版本；隔离测试目录补足修复版本后重跑，不修改全局环境 |

## 验证口径

本地 182 项测试通过，包括核心与可选 PySD、SciPy、Matplotlib、MCP 集成。两条 PySD 固定延迟取整提示对应有意测试的半步时长，没有测试失败。测试加载临时目录的 MCP 1.30.0、lxml 6.1.3 与 Pillow 12.3.0；本机全局旧包没有被擅自替换。Ruff lint/format、Bandit、ShellCheck、Skill 格式与文档链接检查通过。

修正后的 Lookup 示范对照内置引擎与 PySD 的 241 个保存点，Price、Demand 与 Supply 的最大绝对差均为 0，源 MDL 字节未改动。这只验证该示范和当前输入；函数边界由独立测试覆盖，不推广为任意模型的数值等价证明。

Betterleaks 密钥扫描只针对发布范围，未报告泄漏，保留未发布的本地 `AGENTS.md`。OSV 对重新解析的 65 个依赖及补足修复版本后的实际测试依赖 65 项均未报告已知漏洞。首次扫描实际环境发现旧 lxml 6.0.3 与 Pillow 12.2.0 命中公告，已在临时测试目录补足修复版本后重新检查，不能以新解析报告掩盖旧环境。依据为 [lxml 官方安全公告](https://github.com/lxml/lxml/security/advisories/GHSA-vfmq-68hx-4jfw) 和 [Pillow 官方安全公告](https://github.com/python-pillow/Pillow/security/advisories/GHSA-xj96-63gp-2gmr)。全局 Python 仍有低于依赖约束的包，`doctor` 会具体报告；“未发现已知漏洞”仅适用于上述扫描范围，不等于全局环境或全部逻辑均已证明安全。

库存/环形原生导出示范保留既有模型、单位、图面及哈希证据。新增函数回归和查表示例修正通过 Python/PySD 检查；本轮未将它们写为已完成所有原生函数的逐点核验。自然圆弧、符号位置与中文字体仍按具体 MDL 在原生软件审图。

GitHub Actions 已配置三平台矩阵。此前任务受到账号账单锁定影响，在测试前未启动；发布时需检查实际 run/check-run 状态，不能以本机通过或矩阵配置存在代替 Windows/Linux 远程测试通过。

## 保留的边界

- 内置引擎为可测试的标量 Euler 子集，不能替代完整 Vensim 函数、量纲与研究有效性验证。
- PULSE 的非网格边界在不同后端可能不同；需按任务实际跳变时刻比较。
- 自动布局不能保证任意复杂网络零交叉；未知路由保留并报告，原生符号位置需目视验收。
- 文件哈希对应不证明数据是真实观测或研究结论可靠；旧/无清单 CSV 明确来源未验证。
- MCP 工作目录限制是应用约束，不是操作系统沙箱；仍存在可信本地进程可并发改变目录的竞态边界。
- 官方 DSS MCP 与独立 stdio 适配器分开；官方包入口已发现，服务器工具调用没有实测。
- 非商业许可、作者署名、真实 MDL 图源和当前任务输入要求继续保留。
