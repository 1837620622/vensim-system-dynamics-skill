## 反馈图与存量流量图

CLD 表达因果机制，SFD 还必须表达累积和流向。环形外观本身不能证明它是反馈回路，自动布局使用的无向图核心也不能用来宣布增强或平衡性质。

箭头正负与回路 R/B 的具体检查、程序覆盖范围和原生符号放置要求见 [反馈核对](FEEDBACK.md)。

1. 从主要状态量出发，逐步读到影响它的流率，再返回状态。每一步与实际方程或明确的研究机制对应。
2. 默认让主要反馈沿环排列，参数和外生驱动放在相关节点外侧。多个模块独立展开；必要时拆 View，用合法 Shadow 保持联系。
3. 存量矩形、双线流量管道、阀门和边界云各有含义；信息箭头不能替代流率，也不能直接改变存量值。
4. 极性与时滞逐条核对。非单调关系不能为图面完整而猜固定正负号；需要拆分机制时先修改有依据的模型规范，再同步方程。
5. 按实际字号检查端点、文字框、影子括号和整段弧线。不用巨大半圆绕开所有问题；原生打开后再检查是否补出缺失连接。

最终结构图仍须从对应的真实 MDL 原生导出。文献图只作为表达参考，不重绘成当前模型的所谓标准答案。

## 方程如何随图交付

文档中的连续形式应与 MDL 的净流率和初值一致：

\[
S(t)=S(t_0)+\int_{t_0}^{t}\left(\sum_i I_i(\tau)-\sum_j O_j(\tau)\right)\,d\tau.
\]

对应的 `INTEG(净流率, 初值)` 从当前 MDL 读取，不从通式猜参数。文字表述、MDL 变量名和论文中的数学符号用对照表关联；新建业务名默认中文，数学符号可以简写。

| 内容 | 核对方式 |
| --- | --- |
| 存量、流率、辅助量、参数分类 | 与 MDL 定义及草图对象一致 |
| 全部方程和初始条件 | 不仅列核心方程，附录可容纳完整表达式 |
| 变量与时间单位 | 流率为存量单位/时间，原生 Units Check 通过 |
| 参数取值、来源和适用范围 | 区分观测、文献、校准与情景假设，不把示例值当事实 |
| 边界与函数语义 | 说明非负约束、分母为零、查表、外生驱动与延迟初始化 |
| 数值设置 | 记录后端、积分方法、步长、保存间隔和收敛结果 |

不能把存量更新式再乘一次步长后放进 `INTEG` 的流率参数；积分器已处理时间累积。`MAX`、`MIN`、延迟和查表等函数是否适用由机制与量纲决定，不能为了得到好看的趋势随意添加。

## 仿真图按研究问题选择

| 比较目标 | 图件选择 | 需要保留的证据 |
| --- | --- | --- |
| 少量命名政策情景 | 同变量、同坐标，编号或线型加图例 | 情景名、参数变化、相同初值与求解设置 |
| 单因素敏感性 | 每次只改一个参数，原基准同时显示 | 参数原值和实际幅度，不固定为某篇论文的百分比 |
| Monte Carlo 抽样 | 中位线与样本分位带，或有依据的分组 | 分布、样本数、种子、时间网格；分位带不是置信区间 |
| 历史拟合或验证 | 观测与模拟使用可区分标记，必要时补残差图 | 观测来源、时间对齐、校准期与验证期；不能覆盖真实观测 |
| 不同单位的输出 | 分开出图，或明确解释并标注各坐标 | 原始单位和可比范围，不挤在无说明的同一轴上 |

默认采用彩色经典编号图，单曲线与分位带同样用彩色；线型和编号提供额外区分，颜色由当前任务的图件配置统一管理。模型结构图仍为黑色或纯蓝原生箭头。字体按真实字形和目标出版物选择。目标文献偏好无衬线时，使用已安装且覆盖中文的字体配置，不强制照搬另一刊物的要求。

默认无图内标题、图号、图标、水印或成组装饰。变量、情景、时间单位必须可辨认；纵轴单位在坐标标签、图例或图外图注明确写出。不能拿别人的曲线形状反推伪造数据，也不能删掉不符合预期的情景。这些建议是工作流规则，不声称程序自动完成所有研究验证。

## 最后检查

- 在论文实际版宽下查看导出图，中文与数学符号可读，图例不压曲线，黑白打印仍可辨认。
- 逐条核对图例对应的 CSV、参数和 MDL 哈希；命名政策不能自动合并成抽样分位带。
- PNG 按需要使用 600 或 1200 DPI，线稿优先同时交付 PDF/SVG；提高 DPI 不能修复拥挤的版式。
- 数值检查与图面检查分别记录；没有原生证据时明确后端，不能把 PySD/Python 标成 Vensim 原生仿真。
