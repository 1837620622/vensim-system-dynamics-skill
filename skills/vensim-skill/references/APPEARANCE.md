# 图面规则与返工判据

本规则用于真实 Vensim MDL，优先保持模型逻辑和阅读顺序。目标是结构清楚、曲线自然、可以直接在 Vensim 编辑的学术图。

## 图从哪里来

最终模型结构图必须由交付 MDL 在原生 Vensim 中导出或截图。`preview` 的 SVG/HTML 只能定位碰撞；其字体、云、未知图形和裁剪是近似值，不能放入最终报告冒充原生图。Graphviz 只建议节点坐标。不得为了漂亮另画一张与 MDL 不一致的图。

Vensim 新版本若提供“导出为 SVG”，优先原生矢量导出；否则使用软件支持的原生导出或截图。导出后再次核对文件对应的模型、View、字体、箭头和可见范围。禁止截图后擦线、补字或隐藏冲突。

## 外观和语义

| 对象 | 默认处理 | 必须避免 |
| --- | --- | --- |
| 信息箭头 | 全图黑色；用户选蓝时用纯蓝 `0-0-255` | 深蓝、墨色、半透明、多色装饰 |
| 实体流量 | 黑色双线管道，原生阀门与云 | 直接按图形箭头方向猜因果方向 |
| 辅助变量/参数 | 透明文字框，靠近作用对象 | 整齐却远离关系的参数长排、每个变量套装饰框 |
| 存量 | 清楚的原生矩形，稳定的主骨架 | 因排版移动管道端点、流量文字脱离阀门 |
| 圆弧 | 短而舒展、切向进入目标，不穿字 | 巨大半圆包住无关模块、所有边用同一弯曲方向 |
| 极性与延迟 | 有依据才添加，已有值保留 | 按变量名猜正负号、为了整洁清零 |
| 影子变量 | 保留引用身份，逐实例避让 | 合并同名实例、强制隐藏所有影子 |
| 注释 | 必需解释放图外 | 作者水印、生成过程、调试 ID、无依据 R/B 标记 |

既有图保留用户明确设置；统一样式必须按用户选择进行。`academic` 仅作为旧配置的黑色兼容别名，不再代表深蓝。影子的原生字体和括号属于引用语义，不应伪装成新的 Defined 变量。

## 对照原生设置

以 [原生 Arrow 工具](https://www.vensim.com/documentation/22925.html) 和 [Sketch 字段说明](https://www.vensim.com/documentation/24305.html) 为依据，审图时同时核对记录与实际显示：

- 原生箭头头部、粗细、正负极性与延迟符号各有设置。整理圆弧时保留它们，不因为统一黑色而改变方向、加粗全部线条或统一扩大箭头。
- 颜色继承由 `hasf` 控制，仅改 RGB 字段可能不会改变显示。显式黑色或纯蓝方案会启用箭头颜色位，保留其他字体与极性位；保留模式原样继承原生样式。
- `information_arrow_color` 兼容字段必须与明确选择的黑色/纯蓝方案一致。不能用该字段把 `monochrome` 悄悄覆盖成深蓝，也不能在 `preserve` 下设置一个实际无效的颜色。
- 原生辅助变量是文字，存量是矩形，实体流量是管道与阀门；线条连接到原生对象边界。不得另画巨大的三角形箭头贴到文字上，也不得把每个参数都套上矩形。
- 普通圆弧、折线、垂直折线和 Spline 分别识别。原图中清楚的短直线可以保留，不能为了统一视觉而强行把每条线弯成相同弧度。复杂路线在原生界面逐条核对。

这些规则决定原生对象与语义；留白、模块位置和弧度按当前模型判断。官方字段说明不等于某组固定坐标是官方推荐排版。

## 自然排版的顺序

正负号、R/B 的判断和原生放置方法见 [反馈核对](FEEDBACK.md)。更改线形后必须重新核对符号与箭头的对应关系；几何 `pass` 不包含原生符号字形的精确碰撞，不能据此跳过审图。

新建模型默认 `circular`；旧模型的局部修复仍默认 `refine`。环形是组织反馈关系的起点，不是强制所有变量等距排成一个正圆。已有人工位置优先，不能为了满足形式而增删关系。

`circular` 按实际连接识别独立模块，先剥离外围树枝，再沿核心连接排序；外围参数放到相邻作用对象外侧。这里的核心是图形布局依据，不自动证明 R/B 回路类型。没有闭环的模块也不新增反馈边。CLD 自由节点围成环；SFD 保留存量、阀门、云和流量文字，辅助反馈链沿骨架外侧的环形弧段展开。字号和文字框决定间距；比较两个循线方向后检查整段原生圆弧。

`sketch.circular_gap` 调整布局留白，`sketch.circular_aspect` 调整环的高宽比；省略时按默认显示样式计算，半径随节点尺寸和数量变化。这两项也适用于 `layout` 的 JSON 配置。它们只控制显示，不是模型参数。大型密集关系应按子系统拆分 View，而不是不断放大一个圆。具体命令见 [操作手册](OPERATIONS_GUIDE.md)。

1. 识别主存量—流量链和主要反馈环。相邻环的路径有独立留白，沿环可以连续阅读。
2. 将参数放在它直接影响的流率或辅助量附近。共同驱动放两目标之间；初值放对应库存附近，避免横贯全图。
3. 保留模块内部的位置关系。先就近避让重叠，再考虑全局重新组织；不要铺满画布、强制对称或随机抖动。
4. 普通 Arrow 使用三点确定的原生圆弧，控制点在圆弧上，不是 Bézier 手柄。只对支持的单控制点 Arrow 改写几何。多段、正交、Spline 保留并原生检查。
5. 反向因果边走两侧，不能重合成一条双头线。检查整段圆弧，而不是只检查起点到终点的直线。
6. 同时检查圆弧与文字框、圆弧之间、圆弧与实体管道的关系。优先零交叉；不能靠增加弧度把长线绕到整个模块外。
7. 如果局部路由仍拥挤，拆 View 或使用有意义的 Shadow 引用。Defined 变量的原因必须完整，不能漏画参数后期待 Vensim 不补线。
8. 在实际字号与目标缩放下检查。为中文、英文长名称和 `<影子名称>` 保留宽度。原生打开可能重新计算文字尺寸，必须复核。

## 字体与文字边界

新建中文模型使用可配置的原生字体；默认 `Vensim Sans SC`，`sketch.font_family` 与 `sketch.font_size` 可以按软件版本、平台及目标版面调整。不能将本机私有字体路径写入通用 Skill。用户提供的已有 MDL 保留字体，除非明确需要替换。

原生打开后检查中文、英文、数字、负号、括号和长名称，确认不是方框、问号或意外的字体替代。替换字体或字号后，必须重新检查文字框、影子的 `< >`、流量标签与箭头端点。Python `doctor` 的字体检查只证明 Python 绘图环境，不能代替 Vensim 的原生字体识别。

结果图使用 [Python 图件规则](RESULT_PLOTS.md)。程序在导出前检查实际字形，图件清单记录最终字体族；SVG 将字形转路径，PDF 嵌入字体。不把缺字警告当成可以忽略的美观问题。

## 影子重叠排查

运行 `inspect` 对照 View 与对象 ID，`visual` 的 `shadow_objects` 给出影子实例，`shadow_overlaps` 列出它与其他文字框的冲突。重名实例必须独立处理；不同 View 可以复用 ID，不能用全模型 ID 字典覆盖它们。

默认 `refine` 允许就近移动未锁定的 Shadow，重路由它的合法出线；不改变变量名、`bits`、隐藏层级、方程或箭头端点。若连接到未知路由、实体管道或用户锁定对象，则保留并报告，交给原生编辑。`preserve` 不移动任何节点，所以不能用它解决节点重叠。

影子入线、同 View 重复 Defined、原生新补影子等属于结构检查问题。不能直接按“灰色=错误”删除对象。`27:64` 不是本工具的通用修复方法。

## 可复现的局部位置

布局配置中的 `node_positions` 将唯一、可移动的辅助量或影子锚定到指定位置；同名多个实例应先选单个 View，并在原生界面按对象 ID 局部处理。不得用锚点解锁管道。

```json
{
  "view": "库存调整",
  "layout_mode": "refine",
  "style": "monochrome",
  "move_shadows": true,
  "node_positions": {"需求": [430, 430]},
  "clearance": 6,
  "node_spacing": 24,
  "max_allowed_crossings": 0
}
```

运行 `layout model.mdl --config layout.json --output reviewed.mdl`。建模 JSON 的变量 `position: [x, y]` 固定新建存量和辅助量的位置，流量阀门由存量连接生成。锚点先作为避让障碍再安排其他变量；如果指定坐标本身重叠，保留坐标并在报告中报错，不擅自移动后声称符合要求。

## 交付验收

- 方程字节一致，对象和箭头拓扑一致，极性/延迟/字体/隐藏属性保持。
- 无断链、影子入线、文字重叠、信息线或实体管道穿字；未支持的几何形状单独列出。管道穿字记录在 `physical_node_collisions` 中，不得忽略。
- 零交叉作为默认目标。不可避免的交叉有具体位置和原因，不能用宽松阈值伪装解决。
- 在原生 Vensim 再次打开后，管道方向、阀门连接、字号、曲线、影子均正确。
- Check Model、Units Check 的实际结果保存在图外检查记录中。
- 最终图由已检查 MDL 原生导出，图与模型一一对应；图内不加工作流批注或版权水印。
