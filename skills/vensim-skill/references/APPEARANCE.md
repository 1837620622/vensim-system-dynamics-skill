# 图面与视图规则

本页规定 MDL 草图怎么画。规则来自三处：Vensim 官方约定、Sterman 等人的系统动力学绘图建议、对 256 个公开 MDL 的统计（Vensim 官方手册示例 25 个、Duggan 教材 59 个、SDXorg 测试模型 149 个、研究模型 23 个）。数值都写在代码常量里，排版命令会自动执行，不需要也不允许手写坐标。

## 图元

| 对象 | 画法 | 依据 |
| --- | --- | --- |
| 存量 | 方框，最小 96×48；名字在框内最多折成两行，两行放不下才加宽 | Vensim Conventions：Level 用方框；官方示例存量框中位数约 104×56；教材里 Teacup Temperature 这类长名都是 80×40 的框内折行 |
| 流量 | 双线管道加阀门，流量名在阀门正下方或正上方 30px | Vensim Conventions；研究模型中位数 30px |
| 源与汇 | 云图标，记录写成 `12,id,48,...,10,8,...` | 写成 0 的源汇在 Vensim 中不显示云 |
| 辅助变量、常量 | 只有文字，不加圆圈或其他框；名字按记录宽度折行，碰撞检查按折行后的实际高度算 | Vensim Conventions；Sterman（*Fine-Tuning*，Part II）：变量周围不加圆圈、六边形等符号 |
| 影子变量 | 灰色 `<名称>`，只引出连线 | Vensim Defined & Shadow Variables |
| 信息线 | 普通箭头加一个控制点，画成圆弧 | 官方示例 99% 的单控制点箭头是圆弧 |
| 隐藏对象 | 隐藏层级不为 0 的变量不画，进出它的箭头也不画、不参与检查 | Vensim Hide/unhide：隐藏变量时连同进出箭头一起隐藏 |

## 间距与弧度

| 项目 | 取值 | 官方示例实测 |
| --- | --- | --- |
| 云中心到阀门 | 80px | 中位数 76px |
| 阀门到存量中心 | 不少于 120px，流量名较长时加宽 | 中位数 124px |
| 弧度 k（矢高/弦长） | 目标 0.12，可选 0.06、0.18，必要时直线 | 中位数 0.14，四分位 0.08–0.22，各弦长区间基本一致 |
| 直线占比 | 只在弧线会交叉或擦字时使用 | 研究、教材、官方示例的每模型直线占比中位数分别为 14%、16%、13%（测试模型多为直线，不参与统计） |
| 箭头可见长度 | 生成时不少于 38px；检查时低于 20px 判为不合格 | 官方示例最短的 5% 约 12px，教材约 30px |
| 连线与文字净距 | 生成时 6px；检查时 3px | 官方示例约 10% 的连线离其他文字不到 5px |

两端文字框贴得很近时，弧线的可见部分只剩一小段，20px 下限用来拦住这种情况。方程直接引用 Time、又没有画出 Time 箭头的变量，Vensim 会在它正下方约 29px 处自动加灰色 `<Time>`，排版时要预留这块位置。

## 布局

- 存量—流量链是骨架。单条链从左到右水平排列；几条链按原图的上下顺序成行，行间按跨行连线对齐。相邻两行中心至少隔 200px，两行流量名之间至少留 100px 放辅助变量（教材模型行距中位数约 180px）。
- 主链上跳过中间存量的流量分两种画法：只跳过一个存量、且原图画在主链旁边的（如“留级”），把被跳过的那段改成绕行支路，支路存量画在主链上方或下方，拐角阀门的名字放在夹角内侧；跨过整条主链的（如接种直接从易感到康复），画成主链外侧的直角折线管道，阀门在折线中段。两种画法都取自 Duggan 教材原图。
- 首尾相连的存量环（不少于 4 个存量）排成矩形回路：上排从左到右，下排从右到左，两端竖直连接，物料循环、人员流转这类结构常这样画。
- 参数放在它直接影响的变量旁边；只用于存量初值的参数放在存量正上方或正下方。
- 重要回路沿圆形或椭圆路径走，连线尽量不交叉（Sterman，*Fine-Tuning Your Causal Loop Diagrams*）。
- 回路标记 R/B 留在所属回路内部。重建时先在原图里找出包住标记的最小回路，弧线定下来以后把标记放回这条回路的中间；回路内部放不下时就近找不压线、不压字的位置。
- 图内只放模型对象、极性、延迟标记和回路标记，不加标题、图号、水印、彩色底或说明文字。

官方示例里交叉数为 0（全部视图），教材中位数 1，研究模型中位数 2、90% 分位 19。本 Skill 的标准是零交叉；结构上不可平面时（例如 K3,3），用影子变量引出连线来消除，影子拆分在报告中逐条列出。

## 视图

Vensim 官方说明：视图像书的各页，每个视图讲模型的一部分，可以按生产、财务、客户这类部门划分，视图之间通过变量或影子变量连接（*How Views Work*）。Sterman 指出一次呈现复杂因果图会难以看清回路，应拆开画（*Fine-Tuning*，Part II）。

| 情况 | 做法 |
| --- | --- |
| 定义变量约 40 个以内 | 一个视图（官方示例每视图中位数 9 个变量，教材中位数 12 个，教材 90% 分位 34 个） |
| 更大的模型 | 按子系统分视图，每个视图对应一条主要存量链或一组紧密相关的机制，6–40 个定义变量（设计取值；研究模型每视图中位数 26 个、90% 分位 146 个，需要分视图） |
| 跨视图引用 | 在使用处放影子变量，不重复定义 |
| 不要做的 | 每个变量一个视图、只有两三个变量的碎视图、上百个变量挤在一个视图 |

`build` 的 JSON 里给变量写 `"view": "子系统名"` 即可分视图，引用其他视图的变量时会自动生成影子。流量和它两端的存量必须在同一个视图。`audit` 和 `visual` 会给出视图划分建议：少于 6 个定义变量提示合并，多于 40 个提示拆分，视图总数明显多于"定义变量数 / 10"时提示合并。

## 排版模式

| 模式 | 行为 | 适用 |
| --- | --- | --- |
| `auto`（默认） | 原图合格就不动；否则先试两种小改动：只挪开出问题的个别变量（弧线不动），或只重排弧线（坐标不动）。小改动后合格，或没有交叉、只剩零星文字问题，就保留作者版面并在报告中列出；问题多时才局部避让或整体重建，取缺陷少的结果 | 处理任何已有模型 |
| `natural` | 整体重建：骨架重排、退火、圆弧、必要时影子拆分 | 新建模型（`build` 默认）、原图很乱、用户要求重画 |
| `refine` | 只移动辅助变量和影子，存量、阀门、流量名不动；同时比较“只挪出问题的变量”和“整体避让”，缺陷一样多时取挪动少的 | 想保留大体版面 |
| `preserve` | 坐标不动，只重排弧线 | 只想改弧线或颜色 |

作者画得好的图应该保留。在 Duggan 教材的 Overshoot、SIR Policy 模型上实测，整体重建的效果不如原图，所以 `auto` 只在原图确实有问题时才重建。Overshoot 原图有两处文字相压，另有两条箭头穿过变量名。`auto` 挪开 2 个变量后，文字相压全部消除，穿字只剩作者原来的一条弧线（列在报告中），其余坐标和弧线不动。这些模型收在 [reference_models](../assets/reference_models/README.md)，遇到同类结构时可以先看作者的画法。

`--style monochrome` 把信息线统一成黑色，`native-blue` 统一成 Vensim 传统的纯蓝，`preserve` 保持原色。整体重建默认黑色。教材和测试模型的视图默认箭头色是蓝色（0-0-255），新版官方示例是灰色；论文印刷常用黑色。

## 配置

从 [layout_config.json](../assets/templates/layout_config.json) 开始改。常用键：

| 键 | 作用 |
| --- | --- |
| `view` / `skip_views` | 只处理某个视图，或跳过若干视图 |
| `node_positions` | `{变量名: [x, y]}`，人工固定个别变量，其他变量绕开它 |
| `lock_node_names` / `lock_object_ids` | 锁定变量（按名字或按对象 ID，后者适合同名影子） |
| `split_shadows` / `max_shadow_splits` | natural 是否用影子消除必然交叉（默认开启，最多 6 处） |
| `shadow_visibility` | `orphan`（默认，隐藏没有连线的重复影子）、`all`、`preserve` |
| `seed` | 退火随机种子，同一输入同一种子结果相同 |
| `max_allowed_crossings` | 允许保留的交叉数，默认 0 |

未知的键会直接报错。

## 交付前检查

1. `visual --strict` 通过：无交叉、无压字、无文字重叠、无过短箭头、`<Time>` 预留区空着、云图标能显示。
2. 用 Vensim 打开输出文件，逐个视图查看，运行 Check Model 和 Units Check。
3. 结构图从 Vensim 导出。`preview` 生成的 SVG/HTML 用的是估算字宽，只用来定位问题。
