# 箭头极性与回路

箭头的 `+/-` 和回路的 `R/B` 都按方程判断，不按变量名、曲线涨跌或相关性猜。

## 判断规则

- `+`：其他直接原因不变时，原因增加使结果增加（饱和区可以不变）；`-` 相反。
- 流入对存量为正，流出对存量为负，按 `INTEG` 的净流率判断。
- 回路上各箭头都有依据时，负号个数为偶数是增强回路 R，奇数是平衡回路 B。也可以沿回路追踪一个小变化：回来时同向是 R，反向是 B（Sterman，*Fine-Tuning Your Causal Loop Diagrams*）。R 不代表一定增长，B 不代表一定稳定。
- 只出现在存量初值里的引用只影响初始化，不构成动态反馈。
- 查表、分段函数、分母、阈值等关系的方向可能随取值改变，要说明适用范围，不能整段硬标一个符号。
- 使用 `+`/`-`，不用 `s`/`o`（Richardson 1997；`+`/`-` 对流量到存量的关系同样适用）。

## 工具

```bash
./skill.sh feedback model.mdl --spec model.json --output review/feedback.json
./skill.sh feedback model.mdl --spec model.json --strict
```

`feedback` 读取 MDL 的箭头和方程，对线性组合、常量乘除和 `MIN/MAX` 计算偏导的符号，核对已标的极性和 `model.json` 里 `feedback_loops` 指定的回路。它不会自动穷举所有回路，也不会给箭头补符号。

| 状态 | 含义 |
| --- | --- |
| `verified` | 已标符号与方程一致 |
| `conflict` | 符号与方程方向相反，或 R/B 与路径符号不符；`build` 遇到会拒绝生成 |
| `no_dependency` | 图上有这条线，方程里没有这个依赖，需要回查模型 |
| `needs_review` | 非线性、作用相消或语法未覆盖，需人工判断 |
| `unmarked` | 箭头没有标符号 |

`--strict` 在有冲突或待核对的已标符号时返回非零。改了参数或方程后要重新检查。

## 符号放在哪里

- 正负号放在箭头靠近终点的一侧空白处，看得出属于哪条线，不压字、不压箭头尖。
- R/B 放在所属回路内部的空白处，相邻回路各自标注，不叠在一起。
- 延迟双杠与极性分开放置。
- 在 Vensim 里用 Arrow Options 调整位置，导出后在论文版宽下再看一遍。
