# 正负极性、反馈性质与符号位置

箭头上的正负号和整条回路的 R/B 分别核对。符号依据当前方程与适用范围，不能按变量名、曲线上升下降、统计相关性或圆的顺逆时针判断。

## 语义检查

- `+` / `S`：其他直接原因不变时，原因增加使结果增加，或在饱和区保持不变。
- `-` / `O`：其他直接原因不变时，原因增加使结果减少，或在饱和区保持不变。
- 一个有向闭环中，所有链接符号都有依据时，负链接数为偶数是增强回路 `R`，奇数是平衡回路 `B`。正反馈不等于有益，负反馈不等于有害。
- `R` 不代表存量一定上升；`B` 不保证系统稳定或没有振荡。时间延迟、非线性和多个回路的相互作用必须另外分析。
- 流率进入存量的累积作用为正，流出存量的作用为负，依据 `INTEG` 的净流率公式判断。物理流量线的画法不能替代因果方向判断。
- 指向存量的细信息箭头不自动等同于初值关系：如果来源出现在存量净流率中，检查器按动态流率判断；只出现在 `INTEG` 初值表达式中的关系才标为 `initial`。同时出现在两处时保守地要求人工核对。
- 初值引用只影响初始化，不能拿它补成动态反馈闭环。影子代表同一变量，但图面实例仍独立，不能靠连接进影子制造回路。
- 查表、分段、乘积、分母、阈值等关系要核对适用域。作用可能换号时，在图外记录条件或拆分机制，不能给全范围硬套固定极性。

`links[].polarity` 是当前任务提供的明确标注，可用 `+`、`-`、`S`、`O`；兼容小写 `s/o`。省略表示未标注，不会自动给所有线添加加号。回路在建模规范的 `feedback_loops` 中逐条列出：`name` 为简短名称，`variables` 为按因果顺序排列且不重复的变量名列表，最后一项自动连回第一项；`polarity` 可填 `R` 或 `B`。空白模板中为 `[]`，没有预设业务回路。

直接自反馈可列一个变量，但方程必须有真实动态自依赖。固定延迟回路只使用其输入表达式，延迟初值和初始化时长不能作为动态反馈边。

## 自动检查的边界

```bash
./skill.sh feedback work/model.mdl --spec model.json --output review/feedback.json
./skill.sh feedback work/model.mdl --spec model.json --strict
```

检查器读取真实 MDL、箭头和方程，支持线性组合、乘除当前字面常量，以及 `MIN/MAX` 的保守单调符号。它固定其他直接变量，用偏导符号区间作检查，不用某次仿真中的相关性猜因果。`MIN/MAX` 的结论允许平坦区，不证明每个工作点都存在非零作用。

| 报告状态 | 含义与处理 |
| --- | --- |
| `verified` | 已标符号与支持的当前方程符号相容；仍需确认研究机制及适用范围 |
| `conflict` | 符号与可确定的方程方向相反，或 R/B 与路径符号不符；新建拒绝输出 |
| `no_dependency` | 图上关系在对应方程中不存在；回查模型，不能直接删线掩盖问题 |
| `needs_review` | 非线性、作用相消、零导数、未覆盖语法或未映射对象，不能声称已核对正确 |
| `unmarked` | 箭头没有符号，不等于已验证；按图的用途决定是否补充 |

整体 `checked_subset` 只说明已检查范围未发现冲突，不等于全模型证明。`--strict` 遇到冲突或尚待核对的已标符号返回非零；未标注箭头仍明确列出。改变常量、政策参数或方程后重新检查；当前系数为正不代表所有可选参数范围都为正。

检查器核对用户明确列出的回路，不自动穷举所有回路，也不自动生成 R/B 图标。回路路径必须由实际动态方程连接，初值边不参与。通过检查后，Agent 才可按需求在原生图中加入必要的回路符号。

## 符号放置

依据 Vensim 的 [Arrow Options](https://www.vensim.com/documentation/23025.html) 与 [Sketch Options](https://www.vensim.com/documentation/20275.html)，逐条在原生界面检查：

1. 正负号优先靠近对应箭头的目标端，明确属于哪根线；不是贴在目标变量名称上，也不是停在两条交叉线之间。
2. 使用原生的 Arrowhead/Handle 与 Inside/Outside 选项。先尝试箭头头部附近的空白侧；与变量或另一符号挤在一起时换到圆弧另一侧，必要时调整圆弧或节点。
3. Handle 位置只在能保持归属清晰时使用。不能把符号移到远离目标的圆弧中段，让读者误认其对应另一条关系。
4. R/B 放在它所代表回路的内部留白处，靠近主要路径；相邻回路各自对应，不叠在一个圆心。双向和嵌套回路尤其要检查归属。没有空间时拆 View，不缩成难辨的小字。
5. 回路的顺/逆时针图形只跟随实际路径方向，不能用旋转方向代替 R/B。符号用与变量协调的正常字号，不加彩色底、装饰圆或大段回路说明。
6. 延迟双杠与极性分开检查，不能因重新路由覆盖对方。原生字体需覆盖 `+`、`-`、`S`、`O`、`R`、`B`，换字体后重新检查位置。
7. 最后在实际论文版宽下检查原生导出图。符号不得压字、压箭头尖、与其他符号重叠或脱离所属箭头。

布局程序保留原生极性、延迟和位置相关字段，不猜未公开的格式位。几何检查尚不模拟原生符号文字的精确边界；报告中 `symbol_placement_requires_native_review` 始终明确这一点。必须实际审图后，才可在单独验收记录中记为通过。
